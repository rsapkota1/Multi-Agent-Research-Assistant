Multi-Agent Research Assistant using LangChain

A multi-agent AI research assistant built with LangChain, Groq, and Tavily to automate web research, information extraction, report generation, and evaluation. This project demonstrates the fundamentals of Agentic AI, tool-using agents, LLM chains, and workflow orchestration.
